# 무게 추천 로직 (2026-07-25 확정)

AI 루틴 생성 시 세트 `weight`를 채우는 규칙. 루틴 템플릿의 weight는 항상 `null`이며
유저별 추천값이 덮어쓴다. 맨몸(`bodyweight`) 종목은 항상 `null`.

입력: 내부 API 프로필(성별·체중·`level`·`goal`) + 최근 운동기록, 루틴 템플릿의 목표 렙(`target_reps`),
종목 metadata(`primaryMuscles`·`movementPattern`·`equipment`).

## 3계층 폴백

### A. 해당 종목 기록 있음 — 실측 e1RM 기반

```
e1RM       = weight × (1 + reps/30)          # Epley — 기록 세트별 계산, 기간 내 최대값
추천무게    = e1RM / (1 + target_reps/30)     # 목표 렙으로 역산
진행(선택)  = 직전 세션에서 목표 렙 전부 성공 시 × 1.025
```

- `weight = 0`인 세트는 제외 (백엔드 `workout_set.weight_kg`가 NOT NULL default 0 — 맨몸/미기록 인코딩)
- reps > 12인 세트는 Epley 오차가 커지므로 e1RM 계산에서 제외 (12렙 이하 세트만 사용)
- 실측 기반이므로 level·goal 보정 불필요

### B. 해당 종목 기록 없음, 같은 주동근 기록 있음

- 같은 `primaryMuscles`의 기록 종목 중 최대 e1RM × **0.8** (종목 간 전이 안전 계수) → A와 동일하게 목표 렙 역산

### C. 기록 전무 — 성별·체중·레벨·목표 기반 초기값

```
초기 e1RM = 체중(kg) × 패턴 비율 × 레벨 계수 × 목표 계수
추천무게  = 초기 e1RM / (1 + target_reps/30)
```

패턴 비율 (metadata `movementPattern`으로 그룹핑, novice 보수 기준):

| 패턴 그룹 | 남 | 여 |
|---|---|---|
| 스쿼트 계열 | 0.50 | 0.40 |
| 힌지(데드리프트 계열) | 0.60 | 0.45 |
| 수평 푸시(벤치 계열) | 0.35 | 0.20 |
| 수직 푸시(오버헤드 계열) | 0.25 | 0.15 |
| 로우/풀 계열 | 0.35 | 0.25 |
| 고립(컬·레이즈·익스텐션 등) | 0.10 | 0.07 |

레벨 계수 (프로필 `level` — DIFFICULTY enum):

| level | 계수 | 근거 |
|---|---|---|
| `beginner` | 1.0 | 기준값 (novice 스탠다드) |
| `intermediate` | 1.3 | 스탠다드상 novice→intermediate 격차 ~1.25–1.4배 |
| `advanced` | 1.6 | intermediate 대비 ~1.25배 추가 |

목표 계수 (프로필/요청 `goal` — GOAL enum):

| goal | 계수 | 비고 |
|---|---|---|
| `strength` | 1.1 | 고강도 지향 — 초기값 상향 |
| `hypertrophy` | 1.0 | 기준 |
| `weightLoss` · `endurance` | 0.9 | 볼륨·지속 지향 — 하향 |

- 주 강도 조절은 목표 렙 역산이 담당하고, 목표 계수는 보정만 한다 (렙 수가 같아도 목표별 체감 강도 차이 반영).
- 프로필 `level`·`goal`이 `null`이면 각각 `beginner`·`hypertrophy`로 간주 (내부 API 규약 — 기본값 처리는 AI 서버 책임).

## 공통 마무리 규칙

1. **장비별 반올림**: 바벨·스미스머신 2.5kg / 덤벨·케틀벨 2kg / 머신·케이블 5kg 단위 (밴드는 무게 개념 없음 → `null`)
2. **강도 존 클램프**: 최종 %1RM( = 추천무게 ÷ e1RM)이 NSCA 존을 크게 벗어나면 경계로 조정
   — 근력 85%↑(1–6렙) · 근비대 67–85%(6–12렙) · 지구력 67%↓(12렙↑)
3. **워밍업 세트**(`includeWarmup`): 해당 종목 첫 세트를 본 세트 무게 × 0.5로 경량화
4. **설계 원칙 — 낮게 시작해서 빠르게 올린다**: 초기값 오차 비용은 비대칭(과중량 = 부상·이탈, 경량 = 다음 세션 +2.5%로 회복). 모든 추정 계층은 보수 편향.

## 근거

- Epley 공식: 1RM 추정의 사실상 표준 (reps ≤ 10–12 구간에서 정확)
- 강도 존: NSCA/ACSM 트레이닝 가이드라인
- 체중 비율 스탠다드: strengthlevel 계열 집계 (사이트별 "beginner" 정의 편차가 커서 novice 보수치 채택)
- 구 recsys 설계의 `exercise_one_rm` 테이블은 새 백엔드 ERD에서 제외됨 → 1RM은 저장하지 않고 AI 서버가 요청 시 기록에서 계산
